# Tienda de Guitarras

Este proyecto es una tienda en línea dedicada a la venta de guitarras. A continuación se detallan los archivos y su propósito dentro de la aplicación.

## Estructura del Proyecto

```
tienda-guitarras
├── public
│   ├── index.php          # Punto de entrada de la aplicación
│   ├── css
│   │   └── styles.css     # Estilos CSS para la tienda
│   └── js
│       └── main.js        # Código JavaScript para interactividad
├── src
│   ├── views
│   │   ├── home.php       # Vista de la página de inicio
│   │   ├── productos.php   # Vista de la página de productos
│   │   └── contacto.php    # Vista de la página de contacto
│   └── includes
│       ├── header.php      # Encabezado común para todas las páginas
│       └── footer.php      # Pie de página común para todas las páginas
├── README.md               # Documentación del proyecto
```

## Instalación

1. Clona el repositorio en tu máquina local.
2. Navega a la carpeta del proyecto.
3. Asegúrate de tener un servidor web (como Apache) configurado para servir el contenido de la carpeta `public`.

## Uso

- Accede a `public/index.php` en tu navegador para ver la tienda en acción.
- Navega a las diferentes secciones utilizando el menú de navegación.
